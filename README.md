# IPL-Dashboard-Excel-
Created an interactive IPL Dashboard in Excel showcasing season-wise winners, runners-up, Player of the Match, and Player of the Tournament. Includes team-wise match wins by batting and bowling first, top 10 Man of the Match winners, and a donut chart for win distribution. Uses PivotCharts and season filters for dynamic analysis .

# 🏏 IPL Data Analysis Dashboard

## 📌 Project Overview
This project presents an interactive IPL Dashboard created using Microsoft Excel. It provides insights into IPL seasons, team performances, match winners, and player achievements through charts and visualizations.

## 📊 Dashboard Features
- 🏆 Season-wise Winner and Runner-up
- 🌟 Player of the Match and Player of the Tournament
- 📈 Team-wise Match Wins: Bat First vs Bowl First
- 🥇 Top 10 Man of the Match Award Winners
- 📊 Team-wise Winner Distribution using a Donut Chart
- 🎯 Interactive Season Filters for dynamic analysis

## 🛠️ Tools & Technologies
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers and Filters
- Data Visualization

## 🎯 Project Objective
The main objective of this project is to analyze IPL match data, identify team performance trends, and highlight the achievements of top players across different seasons.

## 💡 Key Insights
- Compare team performances when batting or bowling first.
- Identify players with the highest Man of the Match awards.
- Explore IPL season winners and tournament highlights.
- Analyze team-wise winning patterns through charts.
